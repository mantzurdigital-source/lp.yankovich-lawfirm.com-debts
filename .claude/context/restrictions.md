# Restrictions — Adv. Haim Yankovich

This project is a legal services landing page for people dealing with debt, execution cases, insolvency and financial distress.

Claude must follow these restrictions permanently while working on this project.

────────────────────────
COPYWRITING RESTRICTIONS
────────────────────────

Never use these phrases:

- מחיקת חובות
- נמחוק לך את החובות
- תיפטר מהחובות
- נעלים לך את החובות
- פתרון מובטח
- הצלחה מובטחת
- 100% הצלחה
- לא תשלם יותר חובות
- יוצאים בלי לשלם
- נסגור לך הכל

Never promise legal outcomes.

Never create misleading financial promises.

Never imply guaranteed legal success.

Avoid aggressive sales language.

Do not create fear manipulation.

Do not use language that sounds like scam marketing.

────────────────────────
EMOTIONAL TONE RULES
────────────────────────

The user visiting this page is likely under stress.

Possible emotional state:

- anxiety
- fear
- shame
- financial pressure
- confusion
- uncertainty

Claude must create emotional safety.

The tone should feel:

- empathetic
- discreet
- calm
- respectful
- trustworthy
- reassuring

Never create pressure-based urgency.

Avoid countdown timers.

Avoid "limited offer" language.

Avoid pushy CTA language.

────────────────────────
DESIGN RESTRICTIONS
────────────────────────

Do NOT use:

- flashy colors
- neon colors
- overly aggressive red warning colors
- childish UI
- loud animations
- casino-style design
- fake urgency elements

Avoid visual chaos.

Avoid generic landing page templates.

Avoid low-quality stock images.

Do not create sales page style design.

────────────────────────
USER EXPERIENCE RULES
────────────────────────

The page should feel like guidance.

Not sales pressure.

The user must feel:

"There may be a path forward."

Navigation should feel calm and trustworthy.

────────────────────────
LEGAL POSITIONING
────────────────────────

This is a professional legal service.

The page must communicate:

- professionalism
- confidentiality
- legal expertise
- personal guidance
- structured process

Never exaggerate results.

Never overpromise.

Never create false expectations.

This file is mandatory context for every future task in this project.
